SIRIUS TR JOURNAL — GitHub orqali APK yig'ish

1) GitHub'da yangi repository oching (Private bo'lishi mumkin).
2) Shu zip ichidagi BARCHA fayllarni repository ildiziga yuklang
   (Add file > Upload files). Muhim: .github papkasi ham yuklansin
   (yashirin papka — Mac/Windows'da "yashirin fayllarni ko'rsatish" ni yoqing).
   Ildizda bo'lishi kerak: www/, .github/, package.json, capacitor.config.json
3) Repository > Actions bo'limi > "Build APK" avtomatik boshlanadi (5-8 daqiqa).
   Boshlanmasa: Actions > Build APK > Run workflow.
4) Tayyor bo'lgach: repository > Releases > "APK build N" > SIRIUS-TR-JOURNAL.apk
   (yoki Actions > ish > Artifacts).
5) APK ni telefonga yuklab o'rnating (Unknown sources ruxsati kerak).

Dizaynni o'zgartirish: www/index.html ni GitHub'da tahrirlang (Commit) — APK qayta yig'iladi.
